# Build from Android phone using GitHub
1. Create a GitHub repository and upload the project files.
2. Open Actions -> Build DNG Grocery APK -> Run workflow.
3. Wait for the green check.
4. Open the workflow run -> Artifacts -> dng-grocery-debug-apk.
5. Download the ZIP, extract it, and install app-debug.apk on Android.
Note: Firebase login/database will need Firebase configuration before those features work.
