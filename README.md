# DNG Grocery Android Application
Package Name: com.dng.grocery

This is a production-grade native Android grocery delivery application built with
Kotlin, Jetpack Compose Material 3, and Firebase Firestore architecture.

## How to Run in Android Studio:
1. Extract this zip file into a folder.
2. Open Android Studio -> "Open Project" -> select the extracted folder.
3. Allow Gradle to sync.
4. To connect Firebase:
   - Go to Firebase Console (console.firebase.google.com)
   - Add an Android App with package name "com.dng.grocery"
   - Download "google-services.json" and place it inside the "app/" folder.
5. Click Run to install and preview on an Android device or emulator!
